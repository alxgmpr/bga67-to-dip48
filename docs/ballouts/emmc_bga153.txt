# Source: Micron "e.MMC Memory MTFC32GANALEA-WT, MTFC64GANALAM-WT" production
# datasheet, doc 153ball_emmc_v51_100s_j37y_j38y.pdf, Rev. D 10/17 EN
# (CCMTD-284460984-10446). JEDEC/MMC standard version 5.1-compliant per JEDEC
# Standard No. JESD84-B51 (per datasheet's Features section).
#   Figure 3 "153-Ball (Top View, Ball Down)", p.8   -> ball positions below
#   Table 5 "e.MMC Ball Descriptions", p.9           -> symbol definitions
#   Figure 4 "153-Ball WFBGA - 11.5mm x 13.0mm x 0.8mm (Package Code: EA)",
#     p.10 -> 0.5mm TYP pitch, 11.5 x 13.0mm body, row letters A-P (skips I,O)
#     across 14 columns, Ø0.30mm SMD ball pads confirmed.
#
# Literal symbols as printed in Figure 3 (mapped to our overlay/rail names by
# a throwaway script, not committed to this repo; the symbol->signal mapping
# rules stated below are the authoritative record):
#   DAT0-DAT7, CLK, CMD, RST_n, DS  - eMMC signal balls (emmc overlay)
#   VCCM   - NAND flash core supply, 2.70-3.60V     -> VCC
#   VCCQM  - controller core + I/F I/O supply, 1.70-1.95V -> VCCQ
#   VSS    - shared ground                           -> GND
#   VDDIM  - internal regulator node, external decoupling cap only -> AUX_VDDI
#   NC     - no connect, not internally connected    -> None
#   RFU    - reserved for future use, no assigned function -> None
#   VSF2-VSF7 - vendor-specific function, internally connected to each
#              other inside the package, no function defined by this
#              datasheet, not used by this design    -> None
#
# 153 lines below, one per populated ball position, row-major (A1..A14,
# B1..B14, ...). Unpopulated grid positions (the keepout ring around the
# vendor-specific/VSF cluster) are simply absent from this list.
